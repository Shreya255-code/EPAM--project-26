# EPAM Assignment 01 — Aurelia Bank Customer Portal

##  Project Overview

Aurelia Bank Customer Portal is an educational web application developed as part of the EPAM CoE program.

The project demonstrates how HTML, CSS, and JavaScript can be combined to create an interactive and user-friendly banking customer interface.

The application simulates a banking portal where customers can securely log in and access various banking-related features.

---

##  Features

- Customer login and authentication
- Customer ID and password validation
- Show/Hide password functionality
- Enter-key login
- Customer dashboard
- Account overview
- Recent transactions
- Interactive navigation
- Diwali customer coupon registration
- Personalized coupon generation
- Copy coupon code to clipboard
- Customer support section
- Statement information
- Logout functionality
- Responsive and professional banking interface

---
 ## Technologies Used

- **HTML5** — Structure and content
- **CSS3** — Styling, layout, and responsive design
- **JavaScript** — Dynamic functionality, event handling, validation, and DOM manipulation
- **VS Code** — Development environment
- **GitHub** — Version control and project submission

# EPAM Assignment 4 – Git and Version Control

## Objective

The objective of this assignment is to understand Git, Git operations,
the Git lifecycle, online repositories, GitHub and Bitbucket.

## Topics Covered

- Version Control Systems
- Git
- Git Operations
- Git Lifecycle
- Local Repository
- Remote Repository
- GitHub
- Bitbucket
- Branching
- Merging

## Git Lifecycle

Working Directory → Staging Area → Local Repository → Remote Repository

## Git Operations Performed

- git init
- git status
- git add
- git commit
- git log
- git branch
- git switch
- git merge

## Tools Used

- Git
- GitHub
- Visual Studio Code
